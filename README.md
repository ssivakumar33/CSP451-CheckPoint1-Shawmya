# CSP451 CheckPoint 1 Project

This repository was created for **CheckPoint 1 – Introduction to GitHub and Version Control** for the CSP451 course at Seneca Polytechnic. The purpose of this project is to demonstrate Git fundamentals including repository setup, commit history, branching, pull requests, and documentation.

---

## 📦 Project Description

The project includes simple HTML, CSS, and JavaScript files used to simulate a small web project. It focuses on using Git commands and GitHub workflows rather than building a full application. The repository shows the process of version control through multiple commits, feature development through branching, and merging through pull requests.

## 🤝 Contributing Guidelines

This repository follows a basic Git workflow:

1. Create a feature branch:

   ```bash
   git checkout -b feature/branch-name
   ```
2. Make changes and commit using descriptive messages:

   ```bash
   git commit -m "feat: describe update"
   ```
3. Push the branch to GitHub:

   ```bash
   git push origin feature/branch-name
   ```
4. Open a Pull Request for review and merge.

This process encourages clean commit history, organized development, and code review practices.
